# Сложно сосредоточиться

https://github.com/sarabarinamargarita-creator/slozhno-sosredotochitsya-fd

Учебный проект: адаптивный сайт с переключением светлой и тёмной тем.

## Функциональность
- Адаптивная вёрстка (Mobile First) для экранов 375px, 768px и 1024px.
- Переключение цветовых тем: «День», «Неон» (тёмная) и «Авто» (зависит от системных настроек).
- Сетка галереи на основе CSS Grid.
- Стилизация состояний элементов (:hover, :focus-visible, :active).
- Декоративные элементы (уголки, «REC») с использованием псевдоэлементов.

## Стек
- HTML5
- CSS3 (Grid, Flexbox, CSS-переменные, медиазапросы)
- JavaScript (переключение тем)

## Запуск
Открыть файл `index.html` в браузере.
